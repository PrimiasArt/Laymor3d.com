📐 Sơ Đồ Kiến Trúc 3 Lớp (Clean Architecture Rules)

Bấm vào từng lớp bên dưới để xem quy chuẩn trách nhiệm và cách tổ chức mã nguồn:

Lớp 1
Giao Diện (UI - Presentation)
React 19, Three.js WebGL Viewers, Frosted Milk Glass panels.
Lớp 2
Hook Tính Năng (Feature Hooks)
Reactive state, điều phối tương tác người dùng, gọi backend services.
Lớp 3
Backend & Domain Services
Logic cắt lớp 3D, bóc tách giá thành, tích hợp AI đa nguồn, Repositories.

Lớp 1: Giao Diện Người Dùng (UI)

  • Nằm tại src/modules/[module]/ui/
  • Thuần túy là Presentation Components nhận props và state từ Hook.
  • Không chứa logic nghiệp vụ, không fetch API trực tiếp.
  • Chuẩn VisionOS: Kính mờ trắng sữa, đổ bóng không gian nhẹ, điểm nhấn xanh Cyan.

Ví Dụ Cấu Trúc Mã Nguồn

// src/modules/studio/ui/StudioPage.tsx
export default function StudioPage() {
  // Lớp 1 gọi Lớp 2 (Hook) để lấy state & actions
  const { currentModel, handleSlice, isSlicing } = usePrintSlicer();

  return (
    <div className="vision-glass-panel">
      <ThreeCanvasViewer model={currentModel} />
      <button onClick={handleSlice}>Bắt Đầu Cắt Lớp</button>
    </div>
  );
}
